## Зачем этот документ

`dev` отпочковался 2026-09-03 от `370b6ee8` и с тех пор разошёлся с
`origin/main` в обе стороны: у `dev` двенадцать своих коммитов, у `origin/main`
— пятьдесят пять. **Слить `dev` целиком нельзя** — это откатит опубликованное
(§3). Значит у каждого из двенадцати коммитов должно быть названное место, иначе
работа теряется молча.

Назначение сделано **сверкой содержимого файлов**, а не чтением сообщений
коммитов: для каждого файла сравнивался хеш блоба в `dev` и в целевой ветке.
Совпадение хешей — доказательство переноса; совпадение формулировок им не
является.

## 3. Чего делать нельзя

**Не сливать `dev` в `main` целиком.** Ветка отстала по опубликованному:
`WAVE_0_0_03_PLAN.md` в ней описывает состояние до выпуска `0.0.03`. Слияние
вернуло бы документ на сутки назад и стёрло ссылку на
[release receipt](receipts/0.0.03-release.json), где записаны run ID настоящего
GitHub runner, digest артефактов полос и неизменяемая ветка `version/0.0.03`.

Правильный маршрут — четыре кандидата, каждый от `origin/main`:

| Кандидат | Что вносит | Готовность |
| --- | --- | --- |
| `review/g0-phase1` | семь документов фазы 1, семь расписок, G0-дельта редакции 4 | полный набор зелёный, probe 5/5, гейт `rc=0` |
| `review/g0-adr-drafts` | шесть черновиков ADR со статусом `proposed` | ждёт решения владельца о принятии |
| `review/g0-sec03-code` | startup policy, кодовая половина `EXC-0001` | ждёт сведения; операторская половина за владельцем |
| `parked/w1-int-00` | скелет нового контура | запаркован намеренно до вердикта G0 |

После сведения всех четырёх `dev` не содержит ничего своего и подлежит удалению.
До сведения — удалять нельзя.

### Порядок слияния не произволен

`review/g0-phase1` ссылается на файлы, которые вносит `review/g0-adr-drafts`:
восемь ссылок из четырёх документов на `ADR-0007`, `ADR-0008`, `ADR-0010`,
`ADR-0011` и `ADR-0012`. Пока кандидат с черновиками не сведён, эти ссылки в
дереве не разрешаются.

| Откуда | Ссылок |
| --- | ---: |
| `STANDARD_APPLICABILITY_W0-STD-01.md` | 4 |
| `OPS_BASELINE_V1.md` | 2 |
| `LEGACY_SUSTAINMENT_W0-LEG-01.md` | 1 |
| `CRITICAL_JOURNEYS_V1.md` | 1 |

**Следствие:** `review/g0-adr-drafts` сводится раньше `review/g0-phase1` либо
вместе с ним. Обратный порядок оставит в канонической ветке восемь битых ссылок.

Ссылки намеренно оставлены ссылками, а не обычным текстом: они выражают
действительное отношение документов к решениям, и после сведения обоих
кандидатов разрешаются сами. Если владелец предпочтёт, чтобы кандидат был
самодостаточен в любом порядке, ссылки заменяются на упоминания без адреса —
это одна механическая правка.

## 5. Чего этот документ не делает

- **Не принимает ни одного кандидата.** Приёмка и слияние — решение владельца.
- **Не утверждает, что `dev` можно удалять сейчас.** Одиннадцать коммитов из
  двенадцати ещё не опубликованы ни в одной канонической ветке.
- **Не оценивает содержание кандидатов** — только их адресацию. Качество работы
  оценивается расписками задач, а не этим реестром.
